쇼츠 업로더

Shorts Uploader — by 셀프노트 스튜디오 (Selfnote Studio)

무엇을 하나요

쇼츠 업로더는 셀프노트 스튜디오가 운영하는 유튜브 채널에 직접 만든 쇼츠 영상을 올리는 데스크톱 프로그램입니다. 채널 주인이 구글 계정으로 허락하면, 프로그램이 YouTube Data API로 영상을 비공개로 올리고 정해 둔 시각에 공개되도록 예약합니다. 올리기 전에 허락받은 채널 이름이 맞는지 확인합니다.

Shorts Uploader is a desktop tool used by Selfnote Studio to upload its own short videos to its own YouTube channels. After the channel owner signs in with Google and grants access, the tool uses the YouTube Data API to upload each video as private and optionally schedule it to go public at a set time. Before uploading, it checks that the authorized channel is the expected one.

요청하는 권한

  • youtube.upload — 영상 올리기 / upload videos
  • youtube.readonly — 채널 이름과 올린 영상 상태 확인 / read channel name and upload status
